# EV-SENSORS-2026-09-23-01 — optional walk sensors

Scope: the step counter, the barometer and the camera, added on
`feature/ui-daylight-starmap` at `94b1b10`. Each is optional: the walk is unchanged on a device
that lacks one, minus that figure.

## What this does not establish

- **Steps have never executed.** No emulator reports a step counter, so `AndroidStepSource` has
  run only far enough to report itself unavailable. The count, the reboot rebase in the field,
  and the `ACTIVITY_RECOGNITION` permission flow on API 29+ are all unverified on hardware.
- **Climb has no true reading.** The emulator's pressure values are synthetic and flat, so the
  three-metre hysteresis has never been exercised against a real rise. The JVM test covers the
  arithmetic, not the sensor.
- The migration test is written but has not been run; `connectedAndroidTest` was not executed.
- Battery cost of the two extra registrations over a long walk is unmeasured (NFR-05).

## Next

a real step count, one with a genuine climb, one photograph taken outdoors and published.
