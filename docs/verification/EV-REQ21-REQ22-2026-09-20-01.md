## Delivered behavior

- REQ-21: pure Java deterministic scoring with documented initial weights, validity/radius
  filtering, neutral unavailable inputs, stable distance/ID ties and reason codes.
- REQ-22: Recommended/Nearby controls, distance-only Nearby ordering, localized reasons,
  search/venue/unvisited filters over the full candidate set before the top-30 limit.
  The formerly hidden venue filter group is now in the expanded places sheet.
- Existing coordinator selection is never changed by reranking. Mode remains in the destination
  ViewModel during recreation. Visits recorded during an active walk and subsequent history
  deletion update the unvisited state. Late visit reads cannot undo newer results.
- Weather from another area, stale data, timestamps in the future, or observations/fetches older
  than 30 minutes do not influence scores. Visible-screen timers age observations without HTTP;
  expired cards stop displaying them, and stale cards allow explicit refresh.
- Movement of 10 m triggers local reranking; attraction requery stays at 250 m. Save, history,
  time and mode updates do not issue attraction HTTP requests. Reference/paused origin labels
  and retained cache provenance remain visible.
- Empty filtered results can recover when a filter is cleared. Retained rows are updated even
  while permission recovery is visible, without dismissing the recovery notice.
- Profile shows finished journey count, distinct visited-place count and saved-place count.
  Failed reads show an unknown value. Capability checks reflect actual permissions, provider
  state, accelerometer and magnetometer availability without registering sensors.
- The obsolete Memory editor and its fake save/photo actions are removed from navigation.
  Existing finished-journey details remain the photo/publishing flow.
- Weather includes Open-Meteo attribution. Story text no longer unconditionally claims to be a
  seed record; archived text is labelled as a saved snapshot. Existing visit rows do not retain
  detailed source metadata, so unknown original attribution is stated explicitly. OSM place
  records credit OSM and disclose possible Wikipedia/Wikidata description enrichment. This
  change does not reconstruct missing historical per-article/photo metadata.
